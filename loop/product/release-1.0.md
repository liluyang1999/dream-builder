# 《智慧树之森》1.0 成品范围与验收矩阵

## 成品定义

1.0 是一款可独立完成、可重复游玩的 Windows 单人第三人称卡通森林游戏。
具备 WebView2 Evergreen 的设备可离线安装与游玩；缺少运行时的设备首次安装需要联网下载引导程序。
它交付一个高密度盒庭章节，而不是开放世界：玩家从标题界面进入森林，探索三条短路线，
收集三枚光种，发现一段记忆，完成方向净化，使智慧树和环境复苏，并可继续漫游、截图或
重新开始。

首轮目标时长为 10–20 分钟。战斗、联网、经济系统、动态天气、无限地图和角色换装不属于
1.0；这些内容不能以“基本模块”为名扩大首发风险。

## 不可妥协的发布条件

- 安装包与独立 EXE 均可在受支持的 Windows 11 x64 环境启动，且只能启动一个实例。
- 从标题界面到章节结尾不依赖开发工具、网络、命令行或口头解释。
- 设置、存档、暂停、错误恢复、键鼠和手柄、音频、无障碍、制作信息与退出路径完整。
- 核心状态可持久化；旧存档可迁移，损坏存档可恢复或安全隔离，不能静默丢失。
- 卡通森林具有明确的中央树、蘑菇坡、溪流和遗迹地标；净化前后有视觉与声音双通道反馈。
- 全部自动化门禁、目标设备原生冒烟、十分钟性能门禁和安装/卸载检查有可追溯证据。
- 不能用自动化代替五名首次接触玩家的 M2 无提示观察；该证据未完成时必须标为外部门槛。

## 模块验收矩阵

| 模块 | 1.0 必须具备 | 验收证据 |
|---|---|---|
| 标题与会话 | 继续、新游戏、设置、制作信息、退出；游戏内暂停与返回标题 | 组件测试 + 原生键鼠流程 |
| 核心玩法 | 移动、碰撞、检查点、三枚光种、记忆、净化、复苏、结尾与重玩 | 纯逻辑测试 + 浏览器/Tauri 流程 |
| 卡通森林 | 分层地表、成片植被、可辨地标、风格化角色与道具、净化前后环境变化 | 前后截图 + 目标设备性能报告 |
| 音频反馈 | 可调环境音乐、环境层和关键交互音效；首次交互后安全启用 | 音频状态测试 + 原生听测 |
| 输入 | 键鼠与标准手柄均可完成主流程；焦点、模态框和暂停时不误输入 | 归一化输入测试 + 原生流程 |
| 设置与无障碍 | 主题、画质、音量、镜头灵敏度、减少动态、高对比、大文字、提示开关 | 契约/持久化测试 + UI 键盘操作 |
| 存档与恢复 | 自动保存、版本迁移、上一份有效备份、损坏隔离、恢复提示与新档确认 | 单元测试 + 人工破坏存档流程 |
| 错误与离线 | Rust 不可用时浏览器回退；保存/加载/导出失败有中文可恢复提示 | 边界测试 + 断开后端流程 |
| 性能 | 目标设备平均 ≥55 FPS、1% Low ≥30 FPS、>50ms 帧 ≤1% | 归档的十分钟原生 JSON |
| 桌面集成 | 单实例、窗口菜单、截图/导出、版本信息、正确图标和产品文案 | 原生冒烟 + 产物检查 |
| 安装与发布 | NSIS 安装、覆盖升级、卸载、干净启动、校验和、许可证与回滚说明 | 干净 Windows 检查表 + 哈希 |
| 质量与合规 | 格式、静态检查、测试、前端构建、Rust 测试/Clippy、无秘密与临时产物 | CI 与本地完整门禁 |

## 实现依赖顺序

1. 建立会话状态和向后兼容的完整设置契约。
2. 补齐标题、暂停、设置、制作信息、结尾和安全的新游戏流程。
3. 加入程序化音频、手柄输入、存档备份/损坏恢复及对应测试。
4. 将灰盒林地替换为可辨识的卡通森林层，并按画质等级控制开销。
5. 更新版本、产品文案、安装/升级/卸载手册，重建并验证最终产物。
6. 执行完整自动化、浏览器、Tauri 和目标设备验收；真人观察单独归档。
