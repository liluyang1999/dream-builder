# M2 P01–P05 无提示观察包

> 待填写模板，不是已完成证据。仅供主持人使用，不要在玩家开始前展示。不得记录姓名、账号、联系方式、原始按键、玩家路径或其他身份信息。

## 固定构建与设备

| 项目 | 固定值 |
|---|---|
| 公开产品版本 | `1.0` |
| 当前观察候选工作树标识 | （首场前填写并冻结） |
| 当前观察候选 EXE SHA-256 | （首场前填写并冻结） |
| 设备代号 | `M2-WIN-I7-10850H-GTX1650TI` |
| 设备 | Lenovo `20TKCTO1WW` · i7-10850H · GTX 1650 Ti Max-Q |
| 显示 | 3840×2160 @ 59 Hz · Windows 缩放 250% |
| 渲染视口 | 1220×744 CSS px · DPR 2.625 |

归档性能清单只保留采集时构建的身份与测量，不提供可再次启动的旧二进制。开始 P01 前必须把上表两个候选字段替换为当前实际值；P01–P05 任一场之间不得重新构建、覆盖 EXE 或更换设备配置。

每场开始前：

1. 手动关闭上一场仍在运行的游戏；运行 `pnpm m2:verify` 复核归档性能基线，并对当前观察候选运行 `pnpm release:verify` 与 SHA-256 复算。
2. 在帮助页执行“重新开始本章 → 确认重开”，看到首次欢迎提示后停止操作。
3. 将独立计时器归零；时间字段统一填写从 `0:00` 开始的整数秒。
4. 只说：“请体验这段森林旅程，并完成你认为的主要目标。过程中我不会提供操作或路线提示。”
5. 玩家完成、主动放弃、身体不适、技术故障或达到 720 秒时停止。
