| 保存与关闭 | 设置写入排队；Rust 先持久化再提交内存。关闭时刷新当前快照，等待解除异步监听后再正常关闭；失败保留窗口并在所有弹窗之上显示唯一警告。标题和隐藏 HUD 的设置场景均有先失败后通过的回归。 |
| 原生计算与菜单 | 详情命中已有场景元数据；完整 u32 闭区间随机数避免上界溢出，普通区间序列不变。菜单/托盘统一分发，移除重复回调和抢占移动按键的原生快捷键。 |
| 音频与订阅 | 组件卸载释放音频；解锁失败可重试，迟到的异步结果不会复活已释放状态；异步 unlisten 的拒绝与清理纳入测试。 |

| 工具与依赖 | 测试 Vite 缓存与开发服务器隔离并在 finally 清理，避免开发页依赖缓存失效。nanoid 最小升级至 3.3.18，修复 GHSA-2v37-7h3g-55p8；锁定安装与 npm 审计通过。 |
