第一次统计后的保留项还包括旧候选和本轮中间候选；最终交付只保留重新核验的一套候选。
最终重建会再次生成 target，交付收尾必须再清理生成物，不能把首次清理结果冒充最终磁盘复核。

执行 `pnpm store prune` 清除 200 个无引用包（工具报告约 719 MB），使用 `cargo clean` 清理
Rust 调试、增量、旧发布、中间测试与 rustdoc 产物。固定路径清理另覆盖 pnpm 元数据、Vite/Vitest
缓存、前端 dist、Tauri 生成 schema、Playwright 测试资料以及本轮独立应用标识的数据和日志。
删除前验证绝对路径在预期目录内且没有重解析点；不跟随 pnpm store 中指回项目的 junction。

以开始时 235 个 Git 跟踪文件的 SHA-256 清单复核：无文件缺失，变化仅为本轮修复与资料更新，
运行时代码未改动。`.git`、IDE 配置、有效开发依赖、教学资料、历史原始证据和正式玩家数据保留。
临时测试失败日志不作为持久档案；历史测量与已归档结论也不因日期旧而删除。
