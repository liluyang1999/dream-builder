完整模块清单

按职责分组，每个源码文件一行。分组顺序刻意从“不依赖任何框架的纯逻辑”走向 “只做呈现和副作用”，读完这张表就能判断一段新代码应该落在哪一层。

入口与编排 · apps/desktop/src/

main.tsx创建 React 根、安装 StrictMode 与错误边界，按查询参数选择玩家应用或 M2 证据工作台
App.tsx唯一的副作用编排层：设置水合、场景加载、原生订阅、快捷键、导出、根节点状态类
version.ts从 version.json 读出两段式产品版本，前端不另存一份字符串
styles.css应用级样式、浅/深色主题、高对比与大文字状态类、系统减少动态响应
vite-env.d.tsVite 客户端类型与自定义环境变量声明

纯规则层 · game/

gameProgress.ts光种、检查点、记忆、净化、树阶段与章节门的版本化纯状态机
purificationPuzzle.ts四拍方向谜题规则：推进、错误重置、取消，且失败不扣光种
playerInput.ts键盘与标准手柄归一化为移动向量和动作意图，含手柄采样与方向判定
playerMotion.ts相机相对运动、加减速、最大步长分段推进与静态碰撞求解
forestLayout.ts世界边界、圆形与矩形障碍、地标与检查点坐标；碰撞与呈现共用同一份

状态与存档 · state/

store.tsZustand store：设置、会话模式、覆盖层、选择与进度提交，转换仍委托纯 reducer
progressStorage.tsv2 读写、v1 迁移、备份轮换、损坏隔离与恢复状态枚举

跨边界 · ipc/ 与 workers/

ipc/runtime.ts判断当前是否运行在 Tauri 中，决定走原生命令还是浏览器回退
ipc/treeApi.ts唯一的 Rust 客户端：invoke、事件订阅、Zod 校验与失败回退
ipc/nativeCloseGuard.ts关闭前等待设置保存，合并重复关闭请求，保存失败时保留窗口
ipc/errorMessage.ts把 JavaScript Error、Rust 结构化错误与字符串统一成可读提示
ipc/instrument.tsTC39 标准方法装饰器 @logged / @measure，为 IPC 加日志与计时
ipc/asyncSubscriptionScope.ts管理异步返回的 unlisten，处理 StrictMode 重复挂载与卸载竞态
workers/protocol.tsWorker 请求/响应消息类型，用回声 id 关联并发请求
workers/fallbackClient.ts主线程客户端：懒创建 Worker、登记在途 Promise、无 Worker 时同步降级
workers/fallback.worker.tsWorker 线程入口，在主线程之外生成兼容场景
data/fallbackTree.ts浏览器回退的确定性场景生成器，输出与 Rust 相同的 wire 形状

输入与交互 · interaction/

useInteractive.ts把 R3F pointer 事件映射为选择动作
useKeyboardShortcuts.tswindow 级快捷键，绑定一次、回调存 ref，遇模态与输入框自动让路
useModalFocus.ts模态焦点陷阱、初始聚焦、焦点归还与关闭键路由
GamepadNavigator.tsx轮询手柄并做边沿检测，把方向映射为谜题方向键或模态焦点漫游

GroundHalo.tsx树下柔和的加色地面光环

MagicParticles.tsx逐帧模拟的魔法粒子，从 ref 读取后端魔法场，不触发 React 重渲染
LightSeed.tsx光种的三种视觉状态与收集消散表现
MemoryFragment.tsx森林记忆碎片的世界表现与可读提示

RestorationNode.tsx净化节点的沉睡/就绪/净化中/已复苏四态表现

sceneHelpers.ts场景组件共用的纯几何与颜色辅助函数

tauri.conf.json窗口、Mica、CSP、NSIS、WebView2 Evergreen 与产品元数据

tests/scene_contract.rs跨边界集成测试：camelCase 序列化、小写枚举与细节引用完整性
