# 2026-08-09 · 1.0 Windows 当前用户安装生命周期

## 结论

产品版本 1.0 的未签名 Windows x64 候选安装器在当前目标 Windows 用户下完成了安装、
同版本重装、首次启动、WebView2、单实例、正常关闭与卸载闭环。Windows“已安装的应用”、
安装器文件属性和已安装主程序文件属性均只显示两段式版本 1.0。卸载后没有程序集成残留，
玩家数据按既定升级与诊断策略保留。

这份证据只证明本机当前用户的安装生命周期，不把未签名候选包提升为生产发布。候选包仍需
受信任代码签名、干净 Windows 账户覆盖升级、实体手柄完整流程和五名首次接触玩家观察。

## 被测契约

- 公开产品版本：`1.0`
- 安装模式：当前用户 NSIS
- WebView2：Evergreen `downloadBootstrapper`，不固定 Runtime 补丁版本
- Windows 展示面：安装器、主程序和“已安装的应用”只显示 `1.0`
- 候选状态：未使用受信任 Authenticode 证书，仅用于本机验证

## 证据边界

- 本轮以 Windows 窗口句柄、标题、进程和 WebView2 子进程作为系统级首次启动证据，没有把
  未执行的视觉点击验收写成已完成。
- 没有受信任 Authenticode 证书，因此当前文件只能称为候选版。
- 没有在全新 Windows 账户或虚拟机执行首次安装与旧版覆盖升级。
- 没有在本轮用实体手柄走完光种、记忆、净化和章节结尾。
- 没有完成五名首次接触玩家的无口头提示观察。
